# لياقتي 🥊

تطبيق ويب شخصي (PWA) أسجل فيه أكلي ووزني وخطواتي وتماريني. الواجهة عربية من اليمين لليسار، ومصممة للجوال أولاً، وفيه وضع داكن.

- **كل البيانات محفوظة على جهازك** (IndexedDB)، ما فيه تسجيل دخول ولا سيرفر بيانات.
- **يشتغل بدون إنترنت** بعد أول فتح، ما عدا خاصية "اسأل Claude".
- **الذكاء الاصطناعي** (Claude Haiku 5.5) يقدّر القيم الغذائية للأكلات اللي مش موجودة في القاعدة المحلية. المفتاح يبقى على السيرفر ولا يوصل للمتصفح أبداً.

## المميزات

| الصفحة | وش فيها |
|---|---|
| **اليوم** | البروتين اليوم (رقم كبير + كم باقي)، اقتراح أكلة تكمّل البروتين، السعرات المتبقية، دائرة توزيع (بروتين/كارب/دهون)، شريط تقدم لكل هدف، الخطوات، تمرين اليوم، وزن اليوم، نوع اليوم، والتنبيهات الصحية |
| **الأكل** | تكتب "رز أبيض مطبوخ 150 غ" ← يدور في القاعدة المحلية ← إذا ما لقاها يسأل Claude ← تراجع القيم وتعدّلها قبل الحفظ ← تحفظها في القاعدة عشان ما يسأل مرة ثانية. تقسيم حسب الوجبة، "كرر وجبة أمس"، و"وجبات مفضلة" (اضغط ☆ جنب أي وجبة) |
| **النشاط** | الخطوات اليومية (الهدف قابل للتعديل)، التمارين (ملاكمة، سبار، سيكل بالكيلومترات، ضغط، تمرين بيت، أو نوع جديد) مع المدة والشدة والملاحظات، ونوع اليوم |
| **الوزن** | الوزن اليومي (خط باهت) والمتوسط المتحرك لآخر 7 أيام (خط واضح)، ومقاس الخصر مرة بالأسبوع |
| **الإحصائيات** | أسبوع / شهر / 3 شهور: السعرات والبروتين مقابل الهدف، متوسط الوزن، الخطوات، كيلومترات السيكل، أيام التمرين، سلسلة أيام هدف البروتين 🔥، أكثر 5 أكلات أعطتك بروتين، ومقارنة هذا الأسبوع باللي قبله |
| **الإعدادات** ⚙️ | الملف الشخصي، جدول التمرين، الأهداف، حدود التنبيهات، المظهر، والنسخ الاحتياطي (تصدير/استيراد JSON) |

### نوع اليوم (تمرين / راحة)
يتحدد تلقائياً بهالترتيب:
1. إذا غيّرته يدوياً لهذا اليوم ← يمشي على اختيارك
2. إذا سجلت تمرين في اليوم ← يوم تمرين
3. حسب الجدول: **السبت والثلاثاء ملاكمة، الخميس سبار، الجمعة سيكل**
4. غير كذا ← يوم راحة

### الأهداف اليومية (قابلة للتعديل من الإعدادات)
| | سعرات | بروتين | دهون (25%) | كربوهيدرات (الباقي) |
|---|---|---|---|---|
| يوم تمرين | 1900 | 110 غ | 53 غ | 246 غ |
| يوم راحة | 1700 | 110 غ | 47 غ | 209 غ |

### التنبيهات الصحية
- السعرات في نهاية اليوم أقل من **1800** ← تنبيه لطيف مع اقتراح وجبة خفيفة (يطلع لليوم بعد الساعة 9 بالليل، ولأمس)
- متوسط الوزن (7 أيام) نزل أكثر من **0.5 كغ بالأسبوع** ← تنبيه إنك لازم تزيد الأكل
- البروتين أقل من **80 غ** ← تذكير بالبروتين

> ⚠️ **ملاحظة مهمة:** هدف يوم الراحة (1700) أقل من حد تنبيه السعرات (1800)، فلو أكلت حسب الهدف بالضبط بيطلع لك تنبيه. جسمك لسا يكبر وتتمرن ملاكمة، فراجع أرقام السعرات مع أهلك وطبيب أو أخصائي تغذية قبل ما تعتمد عليها.

## التشغيل خطوة بخطوة

### 1. ثبّت Node.js
نزّل **Node.js 20 أو أحدث** من [nodejs.org](https://nodejs.org) (اختار نسخة LTS). تأكد إنه انثبت:
```bash
node -v
```

### 2. نزّل المشروع وثبّت المكتبات
```bash
git clone <رابط المستودع>
cd dfff
npm install
```

### 3. حط مفتاح Claude API
1. ادخل [console.anthropic.com](https://console.anthropic.com) وسجّل (أو خلّ أحد من أهلك يسوي لك حساب، لأنه يحتاج بطاقة دفع).
2. من **API Keys** اضغط **Create Key** وانسخ المفتاح (يبدأ بـ `sk-ant-`).
3. في مجلد المشروع، انسخ الملف `.env.example` باسم `.env.local`:
   ```bash
   cp .env.example .env.local
   ```
4. افتح `.env.local` وحط مفتاحك:
   ```
   ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxx
   ```

> 🔒 الملف `.env.local` موجود في `.gitignore` يعني ما ينرفع على GitHub. المفتاح يُستخدم فقط في `src/app/api/estimate/route.ts` على السيرفر، والمتصفح ما يشوفه أبداً. لا ترسل المفتاح لأحد.
>
> 💰 الموديل المستخدم Claude Haiku 5.5 رخيص جداً، وكل أكلة تسأل عنها مرة وحدة بس (بعدها تنحفظ في القاعدة المحلية). التطبيق يشتغل عادي بدون مفتاح، بس زر "اسأل Claude" بيطلع خطأ، وتقدر تستخدم "إدخال يدوي".

### 4. شغّل التطبيق
```bash
npm run dev
```
افتح [http://localhost:3000](http://localhost:3000) في المتصفح.

للنسخة النهائية (أسرع، وفيها خاصية العمل بدون إنترنت):
```bash
npm run build
npm start
```

### 5. شغّل الاختبارات (اختياري)
```bash
npm test
```

## إضافته على الجوال 📱

خاصية "أضف للشاشة الرئيسية" والعمل بدون إنترنت تحتاج رابط **HTTPS**، فأسهل طريقة إنك ترفعه على **Vercel** (مجاني):

### الطريقة المنصوح فيها: Vercel
1. ارفع المشروع على حسابك في GitHub.
2. ادخل [vercel.com](https://vercel.com) وسجّل بحساب GitHub.
3. اضغط **Add New → Project** واختار المستودع.
4. قبل ما تضغط Deploy، افتح **Environment Variables** وأضف:
   - Name: `ANTHROPIC_API_KEY`
   - Value: مفتاحك
5. اضغط **Deploy**، وبعد دقيقة يعطيك رابط مثل `https://lyaqa-xxx.vercel.app`.

> الرابط عام، أي أحد عنده الرابط يقدر يفتح التطبيق ويستخدم زر Claude على حسابك (بياناتك نفسها تبقى على جوالك وما أحد يشوفها). لا تنشر الرابط، ومن [console.anthropic.com](https://console.anthropic.com) تقدر تحط حد للصرف الشهري.

### بعدين على الجوال
**آيفون (Safari):**
1. افتح الرابط في **Safari** (لازم Safari بالذات).
2. اضغط زر **المشاركة** (المربع والسهم).
3. اختار **إضافة إلى الشاشة الرئيسية**، ثم **إضافة**.

**أندرويد (Chrome):**
1. افتح الرابط في **Chrome**.
2. اضغط القائمة ⋮ ← **تثبيت التطبيق** (أو **إضافة إلى الشاشة الرئيسية**).

صار عندك أيقونة "لياقتي" تفتح التطبيق بشاشة كاملة مثل أي تطبيق، ويشتغل بدون إنترنت.

### بديل: على شبكة البيت (بدون رفع)
```bash
npm run build
npm start -- -H 0.0.0.0
```
وافتح من الجوال `http://<IP جهازك>:3000` (لازم الجوال والكمبيوتر على نفس الواي فاي). تقدر تسجّل وتستخدم كل شي، بس **خاصية العمل بدون إنترنت ما تشتغل** لأن الرابط مش HTTPS.

## النسخ الاحتياطي 💾
البيانات محفوظة في متصفح الجهاز نفسه، يعني:
- لو مسحت بيانات المتصفح أو غيّرت الجوال، تروح البيانات.
- البيانات اللي على الكمبيوتر غير اللي على الجوال.

عشان كذا: **الإعدادات ⚙️ ← تصدير JSON** كل أسبوع أو أسبوعين، واحفظ الملف (مثلاً في iCloud أو Google Drive). وللرجوع: **استيراد JSON** (ينبهك إنه بيستبدل البيانات الحالية).

## هيكل الملفات

```
src/
├── app/
│   ├── page.tsx              # الشاشة الرئيسية (اليوم)
│   ├── food/page.tsx         # سجل الأكل
│   ├── activity/page.tsx     # الخطوات والتمارين
│   ├── weight/page.tsx       # الوزن والخصر
│   ├── stats/page.tsx        # الإحصائيات
│   ├── settings/page.tsx     # الإعدادات والنسخ الاحتياطي
│   ├── api/estimate/route.ts # Claude (على السيرفر فقط)
│   ├── manifest.ts           # بيانات PWA
│   └── layout.tsx            # RTL + الوضع الداكن + شريط التنقل
├── components/               # الأزرار، الرسوم البيانية، إضافة أكلة…
└── lib/
    ├── db.ts                 # قاعدة البيانات (Dexie / IndexedDB)
    ├── foods-seed.ts         # الأكلات الشائعة (القيم لكل 100 غ)
    ├── food-match.ts         # فهم النص والبحث بالعربي
    ├── targets.ts            # الملف الشخصي، الجدول، الأهداف
    ├── stats.ts              # المتوسطات، السلسلة، التنبيهات، الاقتراحات
    └── backup.ts             # التصدير والاستيراد
public/sw.js                  # Service Worker (العمل بدون إنترنت)
tests/                        # اختبارات Vitest
```

### تعديل الأكلات الافتراضية
عدّل `src/lib/foods-seed.ts`. الأكلات تنضاف للقاعدة **أول مرة بس** تفتح التطبيق، فإذا عدّلت قيمة لأكلة موجودة، عدّلها من التطبيق (افتح الأكلة ← "القيم لكل 100 غ" ← فعّل "احفظ التعديل").

### بعد أي تحديث للكود
إذا رفعت نسخة جديدة وما ظهر التحديث على الجوال، سكّر التطبيق وافتحه مرتين. وإذا غيّرت `public/sw.js` نفسه، غيّر `VERSION` اللي فيه.
